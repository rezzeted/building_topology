# Генератор топологии здания

Проект строит планировку по графу здания: помещения, стены, проёмы и связи между комнатами. Нормативное описание — `TZ.md`. Геометрия плана первична, чертёж строится по ней.

Язык — Python 3, солвер — Google OR-Tools CP-SAT. На другой язык проект не переписывать.

## Git

Сообщение коммита описывает только изменение.

- Не помечай коммит как сделанный в Cursor: ни в теме, ни в теле, ни в трейлерах. Не пиши `Made with Cursor`, `Generated with Cursor`, `Generated by Cursor` и любые похожие пометки.
- Не добавляй Cursor в соавторы. Не ставь `Co-authored-by` с Cursor, `cursoragent@cursor.com` или другим адресом Cursor.
- Перед коммитом проверь сообщение. Если такая пометка или соавтор уже попали в текст — убери их.

## Среда

Если команда, зависимость или инструмент недоступны и из-за этого задача не выполняется, не подменяй окружение обходным путём и не делай вид, что всё работает. Скажи пользователю, что нужно настроить среду, и чего именно не хватает.

Установка: `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt`. Для PNG нужна системная библиотека cairo (`libcairo2`) и шрифт DejaVu Sans.

- Запуск: `.venv/bin/python -m building_topology examples/05_tz_example_2f.json -o out/05 [--time-limit 30]`.
- Тесты: `.venv/bin/python -m unittest discover -s tests`.

## Код

- `problem.py` — чтение и проверка входа (раздел 5 ТЗ).
- `model.py` — модель CP-SAT и поиск: все этажи одной моделью, сначала прямоугольные этажи, затем контур с выемками; цели раздела 8 по очереди, отклонения площадей по этажам снизу вверх. По умолчанию стены верхних этажей стоят на стенах нижних, при необходимости на несущих стенах 300 мм. С `structure.allow_beams` правило опоры снимается.
- `layout.py` — стены, участки, проёмы, сетка клеток этажа (`Grid`), балки и колонны под висящими стенами (при `allow_beams`), `layout.json`.
- `check.py` — независимая проверка готового плана по разделам 6–7, включая опору стен верхних этажей. План, который её не прошёл, не записывается.
- `render.py` — чертёж SVG и PNG (раздел 10), заливка комнат с площадью дальше 10% от цели.
- `cli.py` — коды выхода 0/2/3/4 из раздела 9.
