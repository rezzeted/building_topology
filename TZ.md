# Техническое задание: генератор планировки по графу здания

Версия 1. Это нормативное описание. Реализация принимает вход, проверяет его, ищет план солвером CP-SAT и пишет геометрию и чертёж. Картинка строится только из найденной геометрии.

## 1. Стек

- Язык: Python 3.
- Солвер: Google OR-Tools, CP-SAT.
- Поиск воспроизводимый: один поток, `random_seed = 1`.
- Лимит времени по умолчанию: 420 секунд (7 минут) на весь поиск. Доказанный оптимум не требуется; если оптимум доказан раньше, поиск заканчивается раньше. Вернуть лучшее допустимое решение, найденное в лимите.

## 3. Координаты

Модель в миллиметрах. Ось X смотрит на восток, ось Y на север. Север на чертеже сверху.

Прямоугольник комнаты — внутренние грани стен: `x`, `y`, `w`, `h`. Площадь комнаты — площадь этого прямоугольника. Стены в неё не входят.

Наружу от каждой внешней грани лежит наружная стена 300 мм. Между внутренними гранями соседних комнат, которые делят стену, зазор ровно 100 мм, у несущей стены — 300 мм.

В выходной геометрии начало координат сдвинуто так, чтобы минимальные наружные грани всего дома вместе с приставными трубами были в нуле.

## 4. Вход

UTF-8, JSON, поле `version` равно 1. Неизвестное поле — ошибка входа. Идентификаторы: непустые строки `[A-Za-z][A-Za-z0-9_-]*`, уникальные среди комнат, лестниц и отопителей.

```json
{
  "version": 1,
  "floors": 2,
  "house_area_m2": 61.52,
  "rooms": [
    {
      "id": "hall",
      "name": "Прихожая",
      "kind": "corridor",
      "floor": 1,
      "area_m2": 6.0,
      "windows": [],
      "exterior_doors": [
        { "facade": "east", "width_mm": 1000, "entrance": true }
      ]
    },
    {
      "id": "living",
      "name": "Гостиная",
      "kind": "room",
      "floor": 1,
      "area_m2": 16.0,
      "windows": [{ "count": 1, "width_mm": 1200, "facade": "north" }]
    }
  ],
  "doors": [
    { "a": "hall", "b": "living" }
  ],
  "stairs": [
    {
      "id": "stair_main",
      "from_floor": 1,
      "to_floor": 2,
      "width_mm": 2400,
      "depth_mm": 2400,
      "rooms": ["stair1", "stair2"]
    }
  ]
}
```

Полный пример — в разделе 11. Поля комнаты:

| Поле | Правило |
| --- | --- |
| `kind` | `room`, `corridor` или `stair` |
| `floor` | Целое от 1 до `floors`. Этаж 1 — нижний. Солвер этаж не меняет |
| `area_m2` | Целевая внутренняя площадь |
| `windows` | Список групп окон. Пустой список значит, что окон нет |
| `windows[].count` | Целое ≥ 1 |
| `windows[].width_mm` | Можно опустить, тогда 1200 |
| `windows[].facade` | `north`, `east`, `south`, `west`. Можно опустить, тогда сторону выбирает солвер |
| `exterior_doors` | Список наружных дверей этой комнаты. Можно опустить |
| `exterior_doors[].facade` | Обязателен |
| `exterior_doors[].width_mm` | Можно опустить, тогда 1000 |
| `exterior_doors[].entrance` | `true` только у единственного входа в дом |
| `use` | Назначение: `living`, `bedroom`, `office`, `kitchen`, `dining`, `hall`, `vestibule`, `bath`, `wc`, `storage`, `boiler_room`, `garage`, `other`. Можно опустить, тогда `other`. У лестничной комнаты не задаётся |

`doors` — неориентированные рёбра. Пара комнат встречается не больше одного раза. Петля запрещена. Ребро означает одну обязательную внутреннюю дверь.

`stairs` описывает шахту. `rooms` перечисляет комнаты шахты снизу вверх, по одной на каждый этаж от `from_floor` до `to_floor` включительно. Эти комнаты есть в `rooms`, у них `kind = stair`, и их этажи совпадают с диапазоном шахты.

`structure` — необязательный объект, правила опоры стен верхних этажей (раздел 7, п. 13–15):

| Поле | Правило |
| --- | --- |
| `allow_beams` | `true` разрешает балки и колонны под стенами верхних этажей. Можно опустить, тогда `false` |
| `max_beam_span_mm` | Наибольший пролёт балки, не меньше 1000. Можно опустить, тогда 6000. Действует при `allow_beams: true` |

`room_area_tolerance_pct` — необязательное целое от 1 до 50: допуск площади комнат `room` и `corridor` в процентах от цели. Можно опустить, тогда 10. Допуск суммы площадей дома остаётся 10%. Комнаты, ушедшие от цели дальше 10%, отмечаются в `layout.json` и на чертеже (разделы 9 и 10).

`heaters` — необязательный список отопителей (раздел 7, п. 16–25). Отопитель и труба стоят внутри прямоугольника комнаты и её площадь не уменьшают.

| Поле | Правило |
| --- | --- |
| `id` | Идентификатор отопителя |
| `kind` | `fireplace` — камин, `solid_boiler` — твердотопливный котёл, `gas_boiler` — газовый котёл с закрытой камерой сгорания, `gas_convector` — газовый конвектор |
| `room` | Комната, в которой стоит отопитель |
| `flue` | Отвод дыма: `chimney` — дымовая труба внутри дома, `facade` — приставная труба снаружи у наружной стены, `wall` — коаксиальный выход через наружную стену. Камин: `chimney` или `facade`. Твердотопливный котёл: `chimney`. Газовые приборы: `wall`. Можно опустить, тогда первый из допустимых |

Комната с газовым прибором — комната, в которой стоит `gas_boiler` или `gas_convector`.

## 5. Проверки входа

Ошибка входа обнаруживается до поиска. Солвер при этом не запускается.

1. Схема, диапазоны этажей и числа комнат, уникальность идентификаторов, кратность сетке.
2. Сумма целевых площадей комнат отличается от `house_area_m2` не больше чем на 10%.
3. Для `room` и `corridor` существует хотя бы один прямоугольник сетки: стороны не меньше минимума своего `kind`, отношение сторон не больше максимума, площадь в допуске `room_area_tolerance_pct` от цели.
4. У лестничной комнаты целевая площадь равна `width_mm * depth_mm` шахты. Обе стороны шахты не меньше 2000 мм.
5. При `floors = 1` список `stairs` пуст. Иначе каждая шахта соединяет соседние этажи сплошным диапазоном, и от этажа 1 по шахтам достижим каждый этаж.
6. В доме ровно одна наружная дверь с `entrance: true`. Она принадлежит комнате этажа 1. Наружные двери есть только на этаже 1.
7. У лестничной комнаты нет наружных дверей.
8. Граф достижимости связен. Ребро графа — запись в `doors`. Лестничная связь — общая шахта у комнат соседних этажей. Из комнаты с входом достижима каждая комната.
9. Требуемая длина проёмов комнаты не больше максимального периметра любого прямоугольника, уже допустимого для этой комнаты по площади и пропорциям. Иначе окно или наружная дверь не могут поместиться ни при какой форме этой комнаты.
10. `use` — из списка раздела 4, у лестничной комнаты не задан. У отопителя `kind` из списка, `room` — существующая не лестничная комната, `flue` допустим для `kind`.
11. Газовый и твердотопливный котлы стоят на этаже 1 (СП 55.13330.2016, п. 7.13). Газовый котёл — в комнате с `use` `kitchen` или `boiler_room` (СП 402.1325800.2018, п. 5.5) и с окном (п. 5.10), в доме не выше 3 этажей (п. Г.16). В одной комнате не больше двух газовых котлов (п. 5.7). Твердотопливный котёл — в комнате с `use = boiler_room`.
12. Газовый конвектор — в доме не выше 2 этажей и не в комнате с `use` `vestibule`, `bath`, `wc` (СП 402.1325800.2018, п. Е.1). Конвекторов в комнате не больше, чем у неё окон (п. Е.3).
13. У комнаты с отопителями есть прямоугольник, допустимый по п. 3, в который каждый её отопитель помещается спиной к стене вместе с зоной перед ним (раздел 7, п. 17), а конвектор ещё и с отступами 200 мм по бокам. У комнаты с конвектором площадь такого прямоугольника не меньше 6 м², а при одном конвекторе меньше 20 м² (СП 402.1325800.2018, пп. Е.1, Е.2). Поиск берёт для комнаты только такие прямоугольники.
14. Нет внутренней двери между двумя комнатами с газовыми приборами: дверь из каждой открывается наружу (СП 402.1325800.2018, п. 5.11).

## 6. Модель плана

Комната — один прямоугольник, оси параллельны осям координат. Одна комната занимает один этаж. Многоугольные и Г-образные комнаты запрещены. Внешний контур этажа прямоугольным быть не обязан.

Клетка сетки внутри дома принадлежит внутренности комнаты или внутренней стене. Проём не вычитает клетку стены: дверь и окно — отметка на участке стены.

Две комнаты делят внутреннюю стену, если их внутренние грани параллельны, зазор между ними ровно 100 мм и проекции пересекаются отрезком положительной длины. Касание углом стеной не считается.

Несущая стена — внутренняя стена 300 мм между двумя комнатами одного этажа. Она бывает только без `allow_beams`, на этажах ниже верхнего, и лежит под наружной или несущей стеной этажа выше. Правила общей стены и дверей для неё те же, что для стены 100 мм.

Участок стены — максимальный отрезок грани комнаты одного вида: либо целиком внешний, либо целиком общий с одной конкретной комнатой.

Объединение внутренностей комнат и внутренних стен одного этажа связно по сторонам клеток и не содержит дыр. Замкнутый двор запрещён. Выемка фасада, открытая наружу, допустима.

Наружная стена толщиной 300 мм строится наружу от каждого внешнего участка. Контур верхнего этажа, включая наружные стены, лежит внутри контура нижнего этажа, включая его наружные стены.

## 7. Ограничения планировки

1. Внутренности комнат одного этажа не пересекаются.
2. Площадь каждой комнаты `room` и `corridor` лежит в пределах `room_area_tolerance_pct` от цели. Площадь лестничной комнаты равна площади шахты.
3. Сумма внутренних площадей всех комнат всех этажей лежит в пределах 10% от `house_area_m2`.
4. Стороны и пропорции соблюдают таблицу констант для своего `kind`.
5. Ребро `doors` реализовано одной внутренней дверью. Комнаты этого ребра делят стену, и хотя бы один их общий участок не короче ширины двери плюс два отступа по 100 мм. Дверь лежит на таком участке целиком.
6. Комнаты без ребра могут делить стену. Двери между ними нет.
7. На одном общем участке не больше одной двери. Между парой комнат не больше одной двери.
8. Окно и наружная дверь лежат целиком на внешнем участке. Если фасад задан, внешняя нормаль участка совпадает с ним: `north` +Y, `east` +X, `south` −Y, `west` −X.
9. От каждого конца участка до проёма остаётся не меньше 100 мм стены. Между двумя проёмами на участке остаётся не меньше 100 мм. Проёмы одного участка не пересекаются.
10. Группа окон размещает ровно `count` окон заданной ширины. Без фасада солвер сам распределяет эти окна по внешним участкам комнаты.
11. Все комнаты одной шахты имеют одинаковые `x`, `y`, `w`, `h`. `w` и `h` равны `width_mm` и `depth_mm` шахты. На каждом этаже шахты у её комнаты есть хотя бы одна внутренняя дверь.
12. Комната с окном или наружной дверью имеет внешний участок достаточной длины. Иначе план недопустим.
13. Позиция стены — отрезок 100 мм вдоль стены на всю её толщину, три клетки поперёк. Стена этажа — клетка его контура, включая наружные стены, не занятая внутренностью комнаты. Позиция наружной или несущей стены этажа выше первого опёрта, если стена этажа ниже лежит под её средней клеткой и ещё под одной из трёх. По умолчанию каждая такая позиция опёрта, балок и колонн нет.
14. При `allow_beams: true` неопёртую позицию наружной стены несёт балка в перекрытии под ней: ось балки проходит через среднюю клетку позиции. Несущую стену балка не несёт.
15. Балка прямая, её длина по оси не больше `max_beam_span_mm`. Каждый конец балки лежит на стене этажа под балкой или на колонне. Колонна стоит внутри контура своего этажа, под ней стена или колонна этажа ниже.

По умолчанию п. 13 входит в поиск. Если такого плана нет, запуск завершается кодом 3, при истёкшем лимите — кодом 4. Сам генератор балки не разрешает.

При `allow_beams: true` поиск не учитывает п. 13. По найденному плану генератор сам ставит балки и колонны. На оси наружной стены верхнего этажа неопёртые позиции подряд образуют пролёт от опоры до опоры. На углу контура пролёт ломается, в точке поворота без опоры ставится колонна. Пролёт длиннее `max_beam_span_mm` делится на равные части, в точках деления — колонны. Колонна, под которой нет стены, повторяется на этаже ниже.

Отопители и трубы, при непустом `heaters`:

16. Отопитель — прямоугольник своего размера внутри своей комнаты, задней гранью на внутренней грани одной из её стен. Камин с `chimney` и твердотопливный котёл стоят спиной к внутренней или несущей стене, за которой по всей ширине корпуса одна соседняя комната: труба идёт во внутренней стене (СНиП 41-01-2003, п. 6.6.8). Газовые приборы и камин с `facade` стоят спиной к внешнему участку: корпус целиком против него и не заходит за наружную стену соседней комнаты во внутреннем углу фасада.
17. Перед камином и твердотопливным котлом во всю ширину корпуса на 1300 мм вглубь комнаты свободная зона, перед конвектором — на 1000 мм. Зона лежит внутри комнаты.
18. Труба `chimney` начинается в корпусе: посередине его ширины, у стены за спиной. Она вертикальна и на этажах выше стоит в том же месте. Пока труба внутри дома, на каждом этаже она лежит во внутренности одной не лестничной комнаты и примыкает хотя бы к одной её стене. Выйдя из дома над каким-то этажом, она дальше вверх идёт снаружи.
19. На этаже, где труба снаружи, она не пересекает контур этажа вместе с наружными стенами. Приставная труба `facade` стоит снаружи вплотную к наружной стене за камином, посередине его ширины, и снаружи на всех этажах.
20. Труба снаружи этажа не закрывает его окна и двери: полоса 100 мм за наружной стеной вдоль проёма свободна.
21. Корпуса отопителей и трубы внутри дома одного этажа не пересекаются и не заходят в зоны п. 17 и п. 22. В полосу 100 мм внутри комнаты вдоль окна не заходит ни корпус, ни труба, кроме конвектора.
22. Зона внутренней двери — ширина двери на 900 мм по обе стороны стены. Зона наружной двери — ширина двери вглубь комнаты на ширину двери, а у двери наружу (п. 25) на 500 мм.
23. Газовый конвектор стоит под окном своей комнаты на той же стене: по ширине корпус целиком в пределах окна. Под одним окном не больше одного конвектора. От боковых стенок корпуса до стен комнаты не меньше 200 мм (СП 402.1325800.2018, п. Е.3).
24. Коаксиальный выход — клетка 100 мм посередине корпуса газового прибора в стене за его спиной. По горизонтали от выхода до окон и дверей того же этажа на том же фасаде не меньше 500 мм, кроме окна над конвектором (СП 402.1325800.2018, пп. Г.17, Е.8). Между выходами одного этажа на одном фасаде не меньше 1000 мм, между выходами двух конвекторов — 300 мм. Расстояние считается между краями клетки выхода и проёма.
25. Дверь из комнаты с газовым прибором открывается из неё: внутренняя — в соседнюю комнату, наружная — на улицу (СП 402.1325800.2018, п. 5.11).

## 8. Цель

Лексикографически, от старшего критерия к младшему:

1. Отклонения площадей по этажам снизу вверх: сначала этаж 1, затем этаж 2 и так далее. На этаже — сумма модулей отклонений площади комнат от целей в клетках сетки. Часть отклонения сверх 10% от цели входит в сумму с весом 10. Нижний этаж получает лучшие площади, верхние подстраиваются под него.
2. Площадь описанного прямоугольника наружного контура первого этажа.
3. Суммарная длина осевых линий внутренних и наружных стен.

Ограничения из раздела 7 не ослабляются ради цели. Длина балок и число колонн в цель не входят.

## 9. Результат запуска

Успех — в выходном каталоге лежат `layout.json`, `floor-<n>.svg` и `floor-<n>.png` для каждого этажа от 1 до `floors`.

Ошибка — этих файлов нет, причина написана в stderr.

| Код | Когда |
| --- | --- |
| 0 | Найден допустимый план |
| 2 | Ошибка входа |
| 3 | Ограничения невыполнимы |
| 4 | Лимит времени истёк, допустимый план не найден |

Если плана с опорой по п. 13 нет, а с балками есть, причина в stderr называет `allow_beams`. При истёкшем лимите в доме из нескольких этажей без `allow_beams` stderr тоже называет этот флаг. Если плана с отопителями нет, а без них есть, причина в stderr называет отопители.

`layout.json` содержит `version`, исходные идентификаторы и геометрию в миллиметрах после сдвига начала координат:

- у комнаты: `id`, `floor`, `x`, `y`, `w`, `h`, `area_m2`, цель `target_area_m2`, у не лестничной комнаты `use`; если площадь `room` или `corridor` отличается от цели больше чем на 10%, ещё `area_flag`: `larger` — больше цели, `smaller` — меньше;
- у стены: этаж, вид `interior`, `exterior` или `bearing`, толщина, концы осевой линии, идентификаторы одной или двух комнат;
- у проёма: этаж, вид `door` или `window`, ширина, положение на стене, комнаты, для наружного проёма фасад, для входа признак `entrance`;
- у балки: `floor` — этаж, над которым лежит перекрытие с балкой, концы оси `start` и `end`, `length_mm`;
- у колонны: `floor`, центр `center`, сторона `size_mm`;
- в `heaters` у отопителя: `id`, `kind`, `floor`, `room`, корпус `x`, `y`, `w`, `h`, сторона стены за спиной `back`, `flue`; у газового прибора ещё `outlet`: фасад `facade` и точка `point` выхода на наружной грани стены;
- в `chimneys` у трубы: отопитель `heater`, прямоугольник `x`, `y`, `w`, `h`, этажи `floors`, на которых труба внутри дома, признак приставной трубы `outside`; у приставной трубы `floors` — все этажи.

В `metrics` кроме площадей и длины стен — общая длина балок `beam_length_m`, число колонн `columns` и число комнат с `area_flag` `rooms_out_of_tolerance`.

Площадь в `layout.json` — фактическая, в м² с двумя знаками.

## 10. Чертёж

Один лист на этаж. Белый фон, чёрные линии, заливка комнат белая. Комната с `area_flag` залита светло-зелёным, если она больше цели, и светло-красным, если меньше. В легенде листа — строка на каждую такую комнату: имя, фактическая и целевая площади, отклонение в процентах. Масштаб чертежа: 1 м = 100 пикселей. Подпись масштаба 1:100. Север сверху, в правом верхнем углу стрелка севера. Линейка 5 м.

Стена рисуется двумя линиями по её граням. В проёме обе линии прерваны.

Внутренняя дверь: четверть окружности в комнату с большей целевой площадью. При равной площади — в комнату с идентификатором, который больше в словарном порядке. Наружная дверь открывается внутрь своей комнаты. Дверь комнаты с газовым прибором открывается из неё (раздел 7, п. 25). Петля стоит в начале проёма по возрастанию координаты вдоль стены.

Окно: разрыв стены, две линии откосов и одна линия остекления по оси стены.

В центре комнаты две строки: имя и фактическая площадь с одним знаком после запятой и суффиксом `м²`. Кегль 14 пикселей. Если строка шире комнаты, кегль уменьшается до наибольшего целого не меньше 8, при котором строка помещается. Иначе подпись комнаты не рисуется, идентификатор выносится в легенду листа.

В лестничной комнате линии ступеней параллельны меньшей стороне, шаг 250 мм, отступ от внутренних граней 100 мм. На всех этажах шахты, кроме верхнего, стрелка вдоль большей оси в сторону возрастания координаты. На верхнем этаже стрелка в обратную сторону.

Балки рисуются на листе этажа, над которым лежит их перекрытие: штриховая линия по оси балки. Колонна — чёрный квадрат 300×300 мм на листе своего этажа. В легенде листа — длина балок и число колонн.

Отопитель — серый прямоугольник корпуса с сокращением: К — камин, ТК — твердотопливный котёл, ГК — газовый котёл, ГКв — газовый конвектор. Дымовая труба — прямоугольник с двумя диагоналями на листах этажа отопителя и всех этажей выше, приставная — на всех листах. Коаксиальный выход — линия поперёк стены от середины корпуса и кружок снаружи. В легенде листа — расшифровка сокращений и знаков. Лист охватывает приставные трубы и полотна дверей, открытых наружу.

## 11. Пример

Вход ниже обязан проходить проверки раздела 5. Он выполним: одно допустимое размещение приведено следом. Это размещение не является требуемым ответом солвера.

Целевая сумма площадей 61,52 м².

| id | kind | этаж | площадь, м² | проёмы |
| --- | --- | --- | --- | --- |
| `hall` | corridor | 1 | 6,00 | вход на восток, 1000 мм |
| `living` | room | 1 | 16,00 | окно на север, 1200 мм |
| `kitchen` | room | 1 | 10,00 | окно на юг, 1200 мм |
| `stair1` | stair | 1 | 5,76 | шахта 2400×2400 |
| `hall2` | corridor | 2 | 4,00 | нет |
| `bed` | room | 2 | 14,00 | окно на север, 1200 мм |
| `stair2` | stair | 2 | 5,76 | шахта 2400×2400 |

Двери: `hall–living`, `hall–kitchen`, `hall–stair1`, `hall2–bed`, `hall2–stair2`. Шахта `stair_main` связывает `stair1` и `stair2`.

Одно допустимое размещение, внутренние грани, миллиметры:

| id | x | y | w | h |
| --- | --- | --- | --- | --- |
| `stair1`, `stair2` | 0 | 800 | 2400 | 2400 |
| `kitchen` | 2500 | 0 | 5500 | 1900 |
| `hall` | 2500 | 2000 | 5500 | 1200 |
| `living` | 0 | 3500 | 6400 | 2500 |
| `hall2` | 2500 | 0 | 1200 | 3200 |
| `bed` | 3800 | 0 | 4200 | 3200 |

Между `living` и комнатами `stair1`, `hall` — несущая стена 300 мм. На ней стоит северная наружная стена второго этажа, остальные его наружные стены стоят на наружных стенах первого. Балки не нужны.

Фактические площади, отличные от цели: `hall` 6,60 м² (+10%), `kitchen` 10,45 м², `hall2` 3,84 м², `bed` 13,44 м². Сумма фактических площадей 61,85 м².

## 12. Вне этой версии

Мебель, балконы, крыльцо, крыша, расчёт балок и колонн на нагрузку, сечения балок, сетка несущих осей, мокрые стояки, строительные нормы сверх чисел этого файла, назначение этажа солвером, двусвет, несколько дверей между одной парой комнат, Г-образные комнаты, внутренний двор.

Из норм на отопители вне версии всё, что не видно в плане: высота трубы над кровлей, высота выходов над землёй и расстояния по вертикали, объём и высота кухни и котельной, мощность приборов, вентиляция, материалы стен и разделки до горючих конструкций, газовые плиты и водонагреватели.
