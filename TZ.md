# Техническое задание: генератор планировки по графу здания

Версия 1. Это нормативное описание. Реализация принимает вход, проверяет его, ищет план солвером CP-SAT и пишет геометрию и чертёж. Картинка строится только из найденной геометрии.

## 1. Стек

- Язык: Python 3.
- Солвер: Google OR-Tools, CP-SAT.
- Поиск воспроизводимый: один поток, `random_seed = 1`.
- Лимит времени по умолчанию: 30 секунд на весь поиск. Доказанный оптимум не требуется. Вернуть лучшее допустимое решение, найденное в лимите.

## 2. Константы

| Константа | Значение |
| --- | --- |
| Шаг сетки | 100 мм |
| Внутренняя стена | 100 мм |
| Наружная стена | 300 мм |
| Допуск площади комнаты и дома | 10% |
| Комната (`room`): минимальная сторона | 1600 мм |
| Комната (`room`): максимальное отношение сторон | 3 |
| Коридор (`corridor`): минимальная сторона | 1200 мм |
| Коридор (`corridor`): максимальное отношение сторон | 8 |
| Лестничная шахта: минимальная сторона | 2000 мм |
| Внутренняя дверь | 900 мм |
| Наружная дверь, если ширина не задана | 1000 мм |
| Наружная дверь: минимум | 900 мм |
| Окно, если ширина не задана | 1200 мм |
| Окно: минимум | 600 мм |
| Отступ проёма от конца участка стены | 100 мм |
| Простенок между проёмами на одном участке | 100 мм |
| Этажей | от 1 до 5 |
| Комнат | от 1 до 40 |
| Пикселей чертежа на метр | 100 |

Линейные размеры входа кратны 100 мм. Площади задаются в м² с шагом 0,01 м²: одна клетка сетки.

## 3. Координаты

Модель в миллиметрах. Ось X смотрит на восток, ось Y на север. Север на чертеже сверху.

Прямоугольник комнаты — внутренние грани стен: `x`, `y`, `w`, `h`. Площадь комнаты — площадь этого прямоугольника. Стены в неё не входят.

Наружу от каждой внешней грани лежит наружная стена 300 мм. Между внутренними гранями соседних комнат, которые делят стену, зазор ровно 100 мм.

В выходной геометрии начало координат сдвинуто так, чтобы минимальные наружные грани всего дома были в нуле.

## 4. Вход

UTF-8, JSON, поле `version` равно 1. Неизвестное поле — ошибка входа. Идентификаторы: непустые строки `[A-Za-z][A-Za-z0-9_-]*`, уникальные среди комнат и среди лестниц.

```json
{
  "version": 1,
  "floors": 2,
  "house_area_m2": 61.52,
  "rooms": [
    {
      "id": "hall",
      "name": "Прихожая",
      "kind": "corridor",
      "floor": 1,
      "area_m2": 6.0,
      "windows": [],
      "exterior_doors": [
        { "facade": "east", "width_mm": 1000, "entrance": true }
      ]
    },
    {
      "id": "living",
      "name": "Гостиная",
      "kind": "room",
      "floor": 1,
      "area_m2": 16.0,
      "windows": [{ "count": 1, "width_mm": 1200, "facade": "north" }]
    }
  ],
  "doors": [
    { "a": "hall", "b": "living" }
  ],
  "stairs": [
    {
      "id": "stair_main",
      "from_floor": 1,
      "to_floor": 2,
      "width_mm": 2400,
      "depth_mm": 2400,
      "rooms": ["stair1", "stair2"]
    }
  ]
}
```

Полный пример — в разделе 11. Поля комнаты:

| Поле | Правило |
| --- | --- |
| `kind` | `room`, `corridor` или `stair` |
| `floor` | Целое от 1 до `floors`. Этаж 1 — нижний. Солвер этаж не меняет |
| `area_m2` | Целевая внутренняя площадь |
| `windows` | Список групп окон. Пустой список значит, что окон нет |
| `windows[].count` | Целое ≥ 1 |
| `windows[].width_mm` | Можно опустить, тогда 1200 |
| `windows[].facade` | `north`, `east`, `south`, `west`. Можно опустить, тогда сторону выбирает солвер |
| `exterior_doors` | Список наружных дверей этой комнаты. Можно опустить |
| `exterior_doors[].facade` | Обязателен |
| `exterior_doors[].width_mm` | Можно опустить, тогда 1000 |
| `exterior_doors[].entrance` | `true` только у единственного входа в дом |

`doors` — неориентированные рёбра. Пара комнат встречается не больше одного раза. Петля запрещена. Ребро означает одну обязательную внутреннюю дверь.

`stairs` описывает шахту. `rooms` перечисляет комнаты шахты снизу вверх, по одной на каждый этаж от `from_floor` до `to_floor` включительно. Эти комнаты есть в `rooms`, у них `kind = stair`, и их этажи совпадают с диапазоном шахты.

## 5. Проверки входа

Ошибка входа обнаруживается до поиска. Солвер при этом не запускается.

1. Схема, диапазоны этажей и числа комнат, уникальность идентификаторов, кратность сетке.
2. Сумма целевых площадей комнат отличается от `house_area_m2` не больше чем на 10%.
3. Для `room` и `corridor` существует хотя бы один прямоугольник сетки: стороны не меньше минимума своего `kind`, отношение сторон не больше максимума, площадь в допуске 10% от цели.
4. У лестничной комнаты целевая площадь равна `width_mm * depth_mm` шахты. Обе стороны шахты не меньше 2000 мм.
5. При `floors = 1` список `stairs` пуст. Иначе каждая шахта соединяет соседние этажи сплошным диапазоном, и от этажа 1 по шахтам достижим каждый этаж.
6. В доме ровно одна наружная дверь с `entrance: true`. Она принадлежит комнате этажа 1. Наружные двери есть только на этаже 1.
7. У лестничной комнаты нет наружных дверей.
8. Граф достижимости связен. Ребро графа — запись в `doors`. Лестничная связь — общая шахта у комнат соседних этажей. Из комнаты с входом достижима каждая комната.
9. Требуемая длина проёмов комнаты не больше максимального периметра любого прямоугольника, уже допустимого для этой комнаты по площади и пропорциям. Иначе окно или наружная дверь не могут поместиться ни при какой форме этой комнаты.

## 6. Модель плана

Комната — один прямоугольник, оси параллельны осям координат. Одна комната занимает один этаж. Многоугольные и Г-образные комнаты запрещены. Внешний контур этажа прямоугольным быть не обязан.

Клетка сетки внутри дома принадлежит внутренности комнаты или внутренней стене. Проём не вычитает клетку стены: дверь и окно — отметка на участке стены.

Две комнаты делят внутреннюю стену, если их внутренние грани параллельны, зазор между ними ровно 100 мм и проекции пересекаются отрезком положительной длины. Касание углом стеной не считается.

Участок стены — максимальный отрезок грани комнаты одного вида: либо целиком внешний, либо целиком общий с одной конкретной комнатой.

Объединение внутренностей комнат и внутренних стен одного этажа связно по сторонам клеток и не содержит дыр. Замкнутый двор запрещён. Выемка фасада, открытая наружу, допустима.

Наружная стена толщиной 300 мм строится наружу от каждого внешнего участка. Контур верхнего этажа, включая наружные стены, лежит внутри контура нижнего этажа, включая его наружные стены.

## 7. Ограничения планировки

1. Внутренности комнат одного этажа не пересекаются.
2. Площадь каждой комнаты `room` и `corridor` лежит в пределах 10% от цели. Площадь лестничной комнаты равна площади шахты.
3. Сумма внутренних площадей всех комнат всех этажей лежит в пределах 10% от `house_area_m2`.
4. Стороны и пропорции соблюдают таблицу констант для своего `kind`.
5. Ребро `doors` реализовано одной внутренней дверью. Комнаты этого ребра делят стену, и хотя бы один их общий участок не короче ширины двери плюс два отступа по 100 мм. Дверь лежит на таком участке целиком.
6. Комнаты без ребра могут делить стену. Двери между ними нет.
7. На одном общем участке не больше одной двери. Между парой комнат не больше одной двери.
8. Окно и наружная дверь лежат целиком на внешнем участке. Если фасад задан, внешняя нормаль участка совпадает с ним: `north` +Y, `east` +X, `south` −Y, `west` −X.
9. От каждого конца участка до проёма остаётся не меньше 100 мм стены. Между двумя проёмами на участке остаётся не меньше 100 мм. Проёмы одного участка не пересекаются.
10. Группа окон размещает ровно `count` окон заданной ширины. Без фасада солвер сам распределяет эти окна по внешним участкам комнаты.
11. Все комнаты одной шахты имеют одинаковые `x`, `y`, `w`, `h`. `w` и `h` равны `width_mm` и `depth_mm` шахты. На каждом этаже шахты у её комнаты есть хотя бы одна внутренняя дверь.
12. Комната с окном или наружной дверью имеет внешний участок достаточной длины. Иначе план недопустим.

## 8. Цель

Лексикографически, от старшего критерия к младшему:

1. Сумма модулей отклонений площади комнат от целей, в клетках сетки.
2. Площадь описанного прямоугольника наружного контура первого этажа.
3. Суммарная длина осевых линий внутренних и наружных стен.

Ограничения из раздела 7 не ослабляются ради цели.

## 9. Результат запуска

Успех — в выходном каталоге лежат `layout.json`, `floor-<n>.svg` и `floor-<n>.png` для каждого этажа от 1 до `floors`.

Ошибка — этих файлов нет, причина написана в stderr.

| Код | Когда |
| --- | --- |
| 0 | Найден допустимый план |
| 2 | Ошибка входа |
| 3 | Ограничения невыполнимы |
| 4 | Лимит времени истёк, допустимый план не найден |

`layout.json` содержит `version`, исходные идентификаторы и геометрию в миллиметрах после сдвига начала координат:

- у комнаты: `id`, `floor`, `x`, `y`, `w`, `h`, `area_m2`;
- у стены: этаж, вид `interior` или `exterior`, толщина, концы осевой линии, идентификаторы одной или двух комнат;
- у проёма: этаж, вид `door` или `window`, ширина, положение на стене, комнаты, для наружного проёма фасад, для входа признак `entrance`.

Площадь в `layout.json` — фактическая, в м² с двумя знаками.

## 10. Чертёж

Один лист на этаж. Белый фон, чёрные линии, заливка комнат белая. Масштаб чертежа: 1 м = 100 пикселей. Подпись масштаба 1:100. Север сверху, в правом верхнем углу стрелка севера. Линейка 5 м.

Стена рисуется двумя линиями по её граням. В проёме обе линии прерваны.

Внутренняя дверь: четверть окружности в комнату с большей целевой площадью. При равной площади — в комнату с идентификатором, который больше в словарном порядке. Наружная дверь открывается внутрь своей комнаты. Петля стоит в начале проёма по возрастанию координаты вдоль стены.

Окно: разрыв стены, две линии откосов и одна линия остекления по оси стены.

В центре комнаты две строки: имя и фактическая площадь с одним знаком после запятой и суффиксом `м²`. Кегль 14 пикселей. Если строка шире комнаты, кегль уменьшается до наибольшего целого не меньше 8, при котором строка помещается. Иначе подпись комнаты не рисуется, идентификатор выносится в легенду листа.

В лестничной комнате линии ступеней параллельны меньшей стороне, шаг 250 мм, отступ от внутренних граней 100 мм. На всех этажах шахты, кроме верхнего, стрелка вдоль большей оси в сторону возрастания координаты. На верхнем этаже стрелка в обратную сторону.

## 11. Пример

Вход ниже обязан проходить проверки раздела 5. Он выполним: одно допустимое размещение приведено следом. Это размещение не является требуемым ответом солвера.

Целевая сумма площадей 61,52 м².

| id | kind | этаж | площадь, м² | проёмы |
| --- | --- | --- | --- | --- |
| `hall` | corridor | 1 | 6,00 | вход на восток, 1000 мм |
| `living` | room | 1 | 16,00 | окно на север, 1200 мм |
| `kitchen` | room | 1 | 10,00 | окно на юг, 1200 мм |
| `stair1` | stair | 1 | 5,76 | шахта 2400×2400 |
| `hall2` | corridor | 2 | 4,00 | нет |
| `bed` | room | 2 | 14,00 | окно на север, 1200 мм |
| `stair2` | stair | 2 | 5,76 | шахта 2400×2400 |

Двери: `hall–living`, `hall–kitchen`, `hall–stair1`, `hall2–bed`, `hall2–stair2`. Шахта `stair_main` связывает `stair1` и `stair2`.

Одно допустимое размещение, внутренние грани, миллиметры:

| id | x | y | w | h |
| --- | --- | --- | --- | --- |
| `stair1`, `stair2` | 0 | 4000 | 2400 | 2400 |
| `hall` | 2500 | 4000 | 5000 | 1200 |
| `kitchen` | 2500 | 1900 | 5000 | 2000 |
| `living` | 2500 | 5300 | 4000 | 4000 |
| `hall2` | 2500 | 4000 | 3400 | 1200 |
| `bed` | 2500 | 5300 | 4000 | 3500 |

Фактическая площадь `hall2` в этом размещении 4,08 м², отклонение от цели 2%. Сумма фактических площадей 61,60 м².

## 12. Вне этой версии

Мебель, балконы, крыльцо, крыша, колонны, несущие оси, мокрые стояки, строительные нормы сверх чисел этого файла, назначение этажа солвером, двусвет, несколько дверей между одной парой комнат, Г-образные комнаты, внутренний двор.
